# 👶🏥 Gertrude's Children Hospital Web-Based System

Welcome to the **Gertrude's Children Hospital Web-Based System** — a secure, modern platform for pediatric healthcare management. Empowering caregivers, lab technicians, and hospital staff, this system streamlines appointment booking, medical records, lab results, and care-team communication with a child-centered approach.

---

## ✨ Features

- 👩‍👧‍👦 **Caregiver Portal**
  - 📝 Register your account in minutes
  - 📅 Book appointments with ease
  - 🔑 Receive unique QR codes for fast check-in
  - 📑 Access medical records, lab results & prescriptions
  - ⏰ Medication reminders for ongoing prescriptions

- 🧪 **Laboratory Management**
  - 📊 Process samples & enter lab results
  - ⏳ Track test status: pending, in progress, completed, critical
  - 🆘 Handle urgent or routine lab orders

- 🏥 **Hospital Staff Tools**
  - 👩‍⚕️ Secure access to pediatric patient profiles
  - 💬 Communicate with care teams & caregivers
  - 📊 Impact: 75+ years of service, 500K+ children treated, 150+ specialists, 98% satisfaction

- 🔒 **Security & Quality**
  - 🛡️ Bank-level encryption
  - 🏅 Excellence in medicine & child-friendly facilities
  - 🏆 Rigorous safety and quality standards

---

## ⚡️ How It Works

1. 📝 **Register** – Create your caregiver account
2. 📅 **Book Appointment** – Choose a convenient slot
3. 🔑 **Receive QR Code** – For fast check-in
4. 🏥 **Visit Hospital** – Scan in and receive care
5. 💝 **Get Care** – Your child gets expert attention

## 🚀 Getting Started

1. **Clone the repo:**
   ```bash
   git clone https://github.com/bennhinn/Gertrudes-Children-Hospital-web-based-system.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure environment:**
   - Setup your Supabase project & credentials  
   - Create `.env.local` with required keys (see `.env.example` if present)

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **View in browser:**  
   [http://localhost:3000](http://localhost:3000)
